# COLLEGE EVENT MANAGEMENT SYSTEM

## Introduction

College Event Management System is a system used to manage college events in an organized way.

## Features

-Create and manage college events
-View upcoming events
-Register for events
-Manage student participation

## Technologies used

-HTML
-CSS
-JavaScript

## Installation 

1.Download the project
2.Open the project folder
3.Open the required files in a browser

## Usage

Students can view available events and register for them.
Faculty can create and manage college events.

## Future Enhancements 

-Add online event registration
-Add notifications for upcoming events
